# ชิงเต่า 8 วัน 7 คืน

คู่มือเที่ยวชิงเต่า 6–13 พ.ย. แยกรายวัน พร้อมแผนที่และปุ่มเปิด AMap

เว็บไฟล์เดียว (`index.html`) ไม่ต้อง build — deploy ด้วย Cloudflare Pages

## ใช้งานออฟไลน์ (PWA)
- ติดตั้งลงหน้าจอโฮมได้ (`manifest.webmanifest`) และเปิดได้แม้ไม่มีเน็ต (`sw.js`)
- ฟอนต์เก็บไว้ใน `fonts/` ไม่ต้องโหลดจาก Google (ซึ่งถูกบล็อกในจีน)
- **ทุกครั้งที่แก้ไฟล์ ให้เปลี่ยน `VERSION` ใน `sw.js`** เพื่อให้มือถือที่ติดตั้งไว้ได้ของใหม่
